1. ภาษาพูด → ภาษาเขียน
2. คำฟุ่มเฟือยที่ควรตัด
3. ประโยค "ถูก" และกรรมวาจก
4. ประโยคยาวที่ต่อด้วย ซึ่ง/โดย/ที่
5. คำเชื่อมตามหน้าที่
6. การ / ความ
7. สรรพนามและการอ้างถึงผู้วิจัย

9. คำทับศัพท์ที่ใช้บ่อย
10. ภาษาอนาคต / อดีต ในแต่ละส่วนของงาน

## 1. ภาษาพูด → ภาษาเขียน

| ภาษาพูด | ภาษาเขียนวิชาการ |
|---|---|
| เยอะ, เยอะมาก | มาก, จำนวนมาก |
| นิดหน่อย | เล็กน้อย |
| ทำให้มันดีขึ้น | ปรับปรุงให้มีประสิทธิภาพมากขึ้น |
| เอามาใช้ | นำมาใช้ |
| ดูว่า | พิจารณาว่า, ตรวจสอบว่า |
| ได้ผลดี | มีประสิทธิผล, ให้ผลเป็นที่น่าพอใจ (ระบุตัวเลขถ้ามี) |
| แบบนี้ | ลักษณะนี้, ดังกล่าว |
| ยังไง / อย่างไรก็ดี (ผิดบริบท) | อย่างไร / อย่างไรก็ตาม |
| เพราะว่า | เนื่องจาก, เพราะ |
| แต่ว่า | แต่, ทว่า |
| อันนี้ / ตรงนี้ | ประเด็นนี้, ส่วนนี้ |
| ค่อนข้างจะ | ค่อนข้าง (หรือระบุระดับเป็นตัวเลข) |
| ทำให้รู้ว่า | ทำให้ทราบว่า, แสดงให้เห็นว่า |
| ใช้ได้ดี | ใช้งานได้อย่างมีประสิทธิภาพ |
| ง่าย ๆ | สะดวก, ไม่ซับซ้อน |
| ไม่ค่อย | ไม่มากนัก, น้อย |
| ทุกวันนี้ | ปัจจุบัน |

| ฟุ่มเฟือย | กระชับ |
|---|---|
| ได้ทำการศึกษา | ศึกษา |
| ทำการทดลอง | ทดลอง |
| มีการพัฒนา | พัฒนา (ถ้ามีประธาน) |
| ในส่วนของ | ด้าน, ใน (หรือตัด) |
| ในเรื่องของ | เรื่อง (หรือตัด) |
| เป็นอย่างมาก | มาก |
| ทั้งนี้ทั้งนั้น | ทั้งนี้ |
| ซึ่งก็คือ | คือ |
| สามารถที่จะ | สามารถ |
| ในปัจจุบันนี้ | ปัจจุบัน |
| เพื่อที่จะ | เพื่อ |
| จึงทำให้ | จึง / ทำให้ (เลือกอย่างเดียว) |

## 3. ประโยค "ถูก" และกรรมวาจก

ภาษาไทยใช้ "ถูก/โดน" กับเรื่องที่ไม่พึงประสงค์ การแปลกรรมวาจก (passive) จากอังกฤษตรงตัวทำให้ประโยคแปร่ง

- ✗ ระบบถูกพัฒนาขึ้นโดยใช้ภาษา Python
- ✓ ระบบพัฒนาขึ้นด้วยภาษา Python / ผู้วิจัยพัฒนาระบบด้วยภาษา Python
- ✗ ข้อมูลถูกเก็บรวบรวมจากแบบสอบถาม
- ✓ ผู้วิจัยเก็บรวบรวมข้อมูลด้วยแบบสอบถาม / เก็บรวบรวมข้อมูลด้วยแบบสอบถาม
- ✗ วงจรถูกออกแบบให้…
- ✓ ออกแบบวงจรให้… / วงจรได้รับการออกแบบให้… (ใช้ "ได้รับการ" อย่างประหยัด)

## 4. ประโยคยาวที่ต่อด้วย ซึ่ง/โดย/ที่

อาการ: ประโยคเดียวยาว 3–4 บรรทัด ต่อด้วย "ซึ่ง" "โดย" "ที่" หลายชั้นจนไม่รู้ว่าประธานคืออะไร

วิธีแก้:
1. หาใจความหลัก (ใครทำอะไร)
2. แยกส่วนขยายเป็นประโยคใหม่
3. เชื่อมด้วยคำเชื่อมที่บอกความสัมพันธ์ (ดูหัวข้อ 5)

- ✗ ผู้วิจัยได้พัฒนาระบบซึ่งเป็นระบบที่ช่วยในการจัดการคลังสินค้าโดยระบบนี้สามารถแจ้งเตือนเมื่อสินค้าใกล้หมดซึ่งจะช่วยลดปัญหาสินค้าขาดสต็อกที่เกิดขึ้นบ่อยครั้ง
- ✓ ผู้วิจัยพัฒนาระบบจัดการคลังสินค้าที่แจ้งเตือนเมื่อสินค้าใกล้หมด ระบบนี้ช่วยลดปัญหาสินค้าขาดสต็อก ซึ่งเกิดขึ้นบ่อยครั้ง

## 5. คำเชื่อมตามหน้าที่

| หน้าที่ | คำเชื่อม |
|---|---|
| เพิ่มเติม | นอกจากนี้, อีกทั้ง, ยิ่งไปกว่านั้น, ประกอบกับ |
| ขัดแย้ง | อย่างไรก็ตาม, ในทางกลับกัน, ทว่า, แม้ว่า…แต่… |
| เหตุ–ผล | เนื่องจาก…จึง…, ด้วยเหตุนี้, ส่งผลให้, ดังนั้น |
| ตัวอย่าง | เช่น, ตัวอย่างเช่น, ได้แก่ (ใช้เมื่อยกครบทุกรายการ) |
| สรุป | โดยสรุป, กล่าวโดยสรุป, จากผลดังกล่าว |
| ลำดับ | ประการแรก…ประการต่อมา…ท้ายที่สุด, ขั้นแรก…จากนั้น… |
| เปรียบเทียบ | ในทำนองเดียวกัน, สอดคล้องกับ, เมื่อเปรียบเทียบกับ |
| อ้างงานอื่น | สอดคล้องกับงานวิจัยของ…(ปี) ที่พบว่า…, ซึ่งแตกต่างจาก… |

หมายเหตุ: "เช่น" ตามด้วยตัวอย่างบางส่วน ห้ามลงท้ายด้วย "เป็นต้น" ซ้อน (เลือกอย่างใดอย่างหนึ่ง: "เช่น ก ข ค" หรือ "ก ข ค เป็นต้น"); "ได้แก่" ใช้เมื่อระบุครบทั้งหมด

## 6. การ / ความ

- **การ** + กริยาแสดงการกระทำ: การศึกษา, การพัฒนา, การทดสอบ
- **ความ** + กริยาแสดงความรู้สึก/สภาพ หรือคุณศัพท์: ความพึงพอใจ, ความเชื่อมั่น, ความถูกต้อง, ความสำเร็จ
- ✗ การพึงพอใจ, ความทดสอบ
- ระวังการขึ้นต้นประโยคด้วย "การ…" ซ้อนกันหลายชั้น ("การศึกษาการพัฒนาการเรียนรู้…") — แปลงเป็นประโยคที่มีประธาน–กริยา

## 7. สรรพนามและการอ้างถึงผู้วิจัย

- งานวิจัย: "ผู้วิจัย" (คนเดียว) / "คณะผู้วิจัย"
- โครงงาน: "ผู้จัดทำ" / "คณะผู้จัดทำ"
- เลือกคำเดียวและใช้ทั้งเล่ม ไม่ใช้ "เรา" "ผม" "ดิฉัน" "ข้าพเจ้า"
- ถ้าไม่จำเป็นต้องมีประธาน ให้ละได้ ("เก็บข้อมูลด้วยแบบสอบถาม")

## 8. การเว้นวรรค เครื่องหมาย ตัวเลข

- เว้นวรรคหน้าและหลังวงเล็บ: `ระบบสารสนเทศ (Information System) ที่…`
- เว้นวรรคระหว่างประโยค/ใจความ ไม่เว้นวรรคกลางคำหรือกลางวลี
- เว้นวรรคหน้า "และ" "หรือ" เฉพาะเมื่อเชื่อมรายการยาว/ประโยค (ตามหลักราชบัณฑิตฯ ยืดหยุ่นได้ แต่ต้องสม่ำเสมอ)
- เว้นวรรคระหว่างตัวเลขกับหน่วย: `25 องศาเซลเซียส`, `100 MHz`
- ร้อยละ: เขียน "ร้อยละ 85.50" (ภาษาไทยนิยม) หรือ "85.50%" — สม่ำเสมอทั้งเล่ม
- ไม่ใช้ `!`, `?` (ยกเว้นคำถามวิจัย), `…` และอีโมจิ
- ไม้ยมก `ๆ` เว้นวรรคก่อนและหลัง: `ต่าง ๆ`
- `ฯลฯ` ใช้น้อย ใช้ "เป็นต้น" แทนได้
- ทศนิยม: ตำแหน่งเท่ากันในตารางเดียวกัน (มักใช้ 2 ตำแหน่ง)
- ค่า p: `p < .05`, `p < .001` (ไม่เขียน `p = 0.000`)

|---|---|
| คอมพิวเตอร์ | คอมพิวเตอร |
| ซอฟต์แวร์ | ซอฟท์แวร์, ซอฟแวร์ |
| ฮาร์ดแวร์ | ฮาร์ดแวร |
| อินเทอร์เน็ต | อินเตอร์เน็ต, อินเตอร์เนท |
| เว็บไซต์ | เว็บไซท์, เวปไซต์ |
| แอปพลิเคชัน | แอพพลิเคชั่น, แอปพลิเคชั่น |
| ดิจิทัล | ดิจิตอล |
| เทคโนโลยี | เทคโนโลยีย์ |
| ฐานข้อมูล (database) | ดาต้าเบส |
| อัลกอริทึม | อัลกอริธึม, อัลกอริทึ่ม |
| ไมโครคอนโทรลเลอร์ | ไมโครคอนโทรเลอร์ |

## 10. กาล (tense) ในแต่ละส่วน

ภาษาไทยไม่มี tense แต่มีคำบอกเวลา ซึ่งต้องสอดคล้องกับสถานะของงาน:

| ส่วน | ข้อเสนอโครงการ | เล่มสมบูรณ์ |
|---|---|---|
| วัตถุประสงค์ | เพื่อพัฒนา… | เพื่อพัฒนา… (เหมือนเดิม) |
| วิธีดำเนินการ | ผู้วิจัย**จะ**เก็บข้อมูล… | ผู้วิจัยเก็บข้อมูล… / **ได้**เก็บข้อมูล… (ใช้ "ได้" อย่างประหยัด) |
| ประโยชน์ | ประโยชน์ที่คาดว่าจะได้รับ | ประโยชน์ที่คาดว่าจะได้รับ (บทที่ 1) / ประโยชน์ที่ได้รับ (บทที่ 5) |
| ผล | — | ผลการวิจัยพบว่า… |

ปัญหาที่พบบ่อย: เปลี่ยน proposal เป็นเล่มสมบูรณ์แล้วยังมี "จะ" ค้างในบทที่ 3
