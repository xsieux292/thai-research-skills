# Thai Research Skills

Skill สำหรับ Claude Code / Claude สำหรับงานเขียนเชิงวิชาการภาษาไทยและอังกฤษ ได้แก่ งานวิจัย บทความวิชาการ วิทยานิพนธ์ รายงานโครงงาน และข้อเสนอโครงการ

| Skill | หน้าที่ |
|---|---|
| `research-reviewer` | ตรวจงานในบทบาทผู้ทรงคุณวุฒิหรือกรรมการสอบ ออกรายงานข้อค้นพบพร้อมระดับความรุนแรง ตำแหน่ง และข้อเสนอแนะ |
| `researcher` | เกลาและแก้งานเขียนให้เป็นภาษาวิชาการ โดยคงความหมาย ข้อมูล และผลการวิจัยเดิม ไม่เติมตัวเลขหรือข้อสรุปที่ไม่มีในต้นฉบับ |

ใช้คู่กันได้: ให้ `research-reviewer` ตรวจก่อน แล้วให้ `researcher` แก้ตามข้อค้นพบ

### รายงานส่งมอบตามขอบเขตงาน (TOR)

ถ้าต้องการเขียนหรือตรวจรายงานที่ส่งมอบต่อผู้ว่าจ้าง (รายงานความก้าวหน้า รายงานฉบับสมบูรณ์ รายงานส่งมอบงวดงาน) **ต้องเตรียมเอกสารขอบเขตงาน (TOR) ฉบับที่ใช้ตรวจรับมาก่อน** skill จะขอเอกสารนี้ก่อนเริ่มงานทุกครั้ง แล้ว:

1. แตกขอบเขตงานเป็นตารางจับคู่ ข้อในขอบเขตงาน → บทในรายงาน → หลักฐานผลงาน → สถานะ (ครบ / บางส่วน / ยังไม่ครบ)
2. วางโครงรายงานหนึ่งบทต่อหนึ่งกลุ่มงาน ใช้ถ้อยคำเดียวกับขอบเขตงาน ทุกบทจบด้วยผลที่วัดได้
3. ปิดท้ายด้วยบทการทดสอบและส่งมอบ และบทสรุปที่ไล่ผลทีละข้อ

สิ่งที่ควรแนบมาพร้อมกัน: เอกสารขอบเขตงาน, งวดงานที่รายงานฉบับนี้ครอบคลุม, แหล่งข้อมูลผลงาน (รายงานเดิม ผลการทดลอง ภาพผล) และแม่แบบของหน่วยงาน (ถ้ามี) รายละเอียดโครงอยู่ใน `skills/researcher/references/scope-report.md`

## การติดตั้ง

**Claude Code (plugin marketplace)**

```
/plugin marketplace add xsieux292/thai-research-skills
/plugin install thai-research-skills@thai-research-skills
```

**ผ่าน skills CLI**

```bash
npx skills add xsieux292/thai-research-skills
```

**คัดลอกเอง**: คัดลอกโฟลเดอร์ใน `skills/` ไปไว้ที่ `~/.claude/skills/`
